Each page here gives the steps for one page of the app. Read them in order the first time, or jump to the page you need. Every page links its full guide on GitHub, which has the details, and opens the same page in the live demo.

## The workflow

The sidebar follows the job, in groups:

1. **Production**: [Production](production.md), where you import the manuscript and follow each chapter, and [Schedule](schedule.md).
2. **Prep**: [Script](script.md) and the [Story Bible](story-bible.md) of names and how to say them.
3. **Record**: the [Booth](booth.md), which follows you as you read.
4. **Edit**: [Editing](editing.md), the chapter's script as the editor.
5. **Review**: [Proof](proof.md), every check's notes in one list, and [Pickups](pickups.md), the lines to record again.
6. **Finish**: [Master & QC](master-and-qc.md) and [Delivery](delivery.md), the platform's rules and its package.

[Settings](settings.md) sits below the groups.

## First steps

1. Install the app from the [releases page](https://github.com/countrymanprime/narration-utils/releases) and start it.
2. Open or create a project: [Getting started](getting-started.md).
3. Learn the sidebar and the header: [Navigation](navigation.md).

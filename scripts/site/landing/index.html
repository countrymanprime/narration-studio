Proof every chapter before the proofer does.

Narration Studio imports your manuscript, listens to the recording with a local Whisper model and marks every skipped or added word. Then it checks your files against the platform's delivery rules.

Quiet where it should be

Your audio stays here

Transcription runs on a local Whisper model. Nothing is downloaded until a feature that needs a model asks you first.

Marks land in your DAW

With REAPER running, the app drops a take marker at every discrepancy, so the fix is one click away.

Install on Windows

Four minutes to a first project

Windows x64 only for now. The installer is per-user, so it asks for no administrator rights.

Get the latest release
  1. Download the setup fileand its .sha256 file to check it.
  2. Run itIt installs to your user folder and adds a Start Menu entry.
  3. Expect a SmartScreen warningThe release is unsigned. Choose More info, then Run anyway.
  4. Start Narration StudioUpdates come from the same releases, and only after you click.

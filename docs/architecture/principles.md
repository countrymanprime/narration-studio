# Design principles

The rules the app's decisions share, each with the ADRs that make it a rule and the question that tests a design against it. Distilled from the ADRs on 2026-10-10. An ADR's Decision text is the authority: where this page and an ADR disagree, the ADR holds and this page is corrected. A rule backed only by a Proposed ADR is marked, because the owner has not accepted it yet.

A design that breaks a principle for good is a decision and gets an ADR ([when to write one](../adr/README.md#when-to-write-an-adr)).

## The principles

### Behaviour the narrator can trust

- **1. Findings suggest; the narrator decides.** An analyzer reports a finding with evidence and a confidence and may suggest one action; it never executes it. Every change to the project is triggered by the narrator, or by a consent they gave once, and can be undone. ([ADR 0032](../adr/0032-analyzers-report-findings-and-never-change-audio-or-manuscript-on-their-own.md), [ADR 0123](../adr/0123-the-approved-marker-is-one-take-marker-for-an-accepted-finding-named-like-transcript-compares-in-one-undo-point.md) (Proposed), [ADR 0146](../adr/0146-cleanup-launchers-open-an-allow-listed-reaper-action-found-by-its-name-and-change-nothing-themselves.md) (Proposed), [ADR 0705](../adr/0705-the-workspace-adds-an-effect-to-a-passage-or-a-chain-to-the-chapters-track-only-after-the-narrator-confirms-and-the-host-names-both-targets.md).) *Ask:* does anything in this change edit audio, the manuscript or the project without the narrator's action?
- **2. Nothing installs, downloads or changes the project without the narrator's click or a one-time consent.** The only automatic outward call is the daily check for a newer release, a metadata request. The update never installs without a click, a model never downloads without asking, chapter sync asks once per project, and a render needs its own one-time approval. ([ADR 0072](../adr/0072-the-app-updates-itself-from-this-repositorys-releases-and-never-installs-without-a-click.md), [ADR 0080](../adr/0080-the-story-bible-language-model-is-a-catalog-asset-unpacked-at-install-and-the-build-asks-before-it-downloads.md), [ADR 0209](../adr/0209-chapter-sync-asks-once-per-project-and-with-consent-every-link-path-runs-one-sync.md), [ADR 0435](../adr/0435-render-with-fx-renders-one-region-at-a-time-into-a-run-folder-with-a-one-time-approval-and-puts-the-narrators-render-settings-back.md) (Proposed).) *Ask:* what is the consent moment, and does the action refuse without it?
- **3. Unverified behaviour ships off.** A command built before the owner's verification pass is refused by the host until the narrator switches it on; promotion is two small edits in one pull request (the port's declaration and the bridge's experimental list) after the pass. ([ADR 0230](../adr/0230-reaper-commands-built-before-the-verification-pass-are-refused-by-the-host-while-the-experimental-switch-is-off.md), [ADR 0400](../adr/0400-promoting-a-reaper-command-from-experimental-to-supported-is-a-one-line-daw-port-declaration-change.md) (Proposed), [ADR 0355](../adr/0355-audacity-is-driven-over-its-scripting-pipe-built-from-the-published-spec-and-verified-by-the-owners-pass.md) (Proposed).) *Ask:* is it Experimental until the owner's pass, and does the host enforce that in one place?
- **4. Local-first; the narrator's data stays on the machine.** Analysis is local; an online source is a Go-only port with a privacy rule and a key sealed in its own file; logs never carry content; a report leaves out amounts unless the narrator opts in. Owner ruling D72: reference data may be fetched freely, but the narrator's and authors' data never leaves. ([ADR 0405](../adr/0405-pronunciation-stays-local-first-behind-cmu-wiktextract-and-espeak-with-merriam-webster-as-the-one-narrator-keyed-online-source.md) (Proposed), [ADR 0356](../adr/0356-the-merriam-webster-key-is-sealed-in-its-own-per-user-file-and-the-online-lookup-is-a-go-only-port-with-a-single-word-rule.md) (Proposed), [ADR 0251](../adr/0251-tool-runs-are-logged-as-json-lines-through-slog-with-a-run-id-and-content-is-never-logged.md), [ADR 0156](../adr/0156-measurement-reads-only-files-picked-this-session-as-one-job-and-fingerprints-the-bytes-it-read.md) (Proposed), [ADR 0406](../adr/0406-the-status-report-leaves-out-the-contracted-amount-and-effective-rate-unless-the-narrator-opts-in.md) (Proposed).) *Ask:* what leaves the machine, to whom, under whose key, and is any content logged?
- **5. Say what was measured; unknown is unknown.** Progress shows real work, a figure comes from a measurement and not an estimate, a result from synthetic data is labelled provisional or uncalibrated, and a value that could not be measured says so. ([ADR 0015](../adr/0015-real-progress-only.md), [ADR 0193](../adr/0193-homes-actual-recorded-is-the-linked-tracks-recorded-length-from-the-saved-project-and-never-an-estimate.md), [ADR 0132](../adr/0132-the-recording-check-ships-0-8-3-8-3-chosen-on-synthetic-fixtures-and-labelled-uncalibrated.md) (Proposed), [ADR 0364](../adr/0364-the-end-to-end-corpus-validation-is-synthetic-and-provisional-until-a-permissioned-project-re-runs-it.md) (Proposed), [ADR 0237](../adr/0237-an-mp3-is-measured-for-its-container-only-from-bounded-frame-headers-and-its-levels-are-not-checked.md) (Proposed).) *Ask:* is any displayed number an estimate, and is every provisional result labelled?
- **6. Precision over recall; offer, do not force.** A guess is offered, and preselected only when confident. A confident two-way match may become a labelled, undoable auto link, and nothing a guess does overrides a manual choice. ([ADR 0020](../adr/0020-entity-extraction-precision-over-recall.md), [ADR 0019](../adr/0019-detected-manuscript-is-offered-not-imported.md), [ADR 0113](../adr/0113-the-teleprompter-suggests-a-chapter-from-the-saved-armed-track-and-preselects-only-a-confident-match.md) (Proposed), [ADR 0202](../adr/0202-a-confident-two-way-match-is-a-real-link-labelled-auto-undoable-and-never-over-a-manual-one.md).) *Ask:* what happens when the guess is wrong, and can it override the narrator's own choice?
- **7. Identity, not position; a stale target is refused.** Things are found by GUID or id, not by a project position or timeline time (a source time inside a found take is fine). A target that no longer resolves changes nothing and is not replaced by a neighbour; a fallback goes to a named source, never to a guess. ([ADR 0121](../adr/0121-going-to-and-looping-a-finding-is-by-guid-and-source-time-makes-no-undo-point-and-stop-restores-what-the-loop-changed.md) (Proposed), [ADR 0349](../adr/0349-the-resume-locate-reads-reapers-live-cursor-and-items-first-and-falls-back-to-the-saved-project-never-to-a-guess.md) (Proposed), [ADR 0700](../adr/0700-the-takes-panel-lists-a-passages-takes-from-the-saved-project-and-chooses-one-by-an-id-the-host-offered.md), [ADR 0026](../adr/0026-manuscript-line-identity-in-item-extension-data.md).) *Ask:* what identifies the thing, and what happens when it is gone?

### Structure of the code

- **8. Reach engines and providers through ports.** Small interfaces with a registry and a capability descriptor; callers ask a resolver what is supported and do not name an adapter or branch on a DAW's kind, except REAPER-only services that have no Audacity equivalent. ([ADR 0300](../adr/0300-every-daw-is-reached-through-one-port-of-small-role-interfaces-and-callers-ask-a-resolver-what-it-supports.md), [ADR 0301](../adr/0301-providers-sit-behind-small-ports-with-a-registry-and-a-capability-descriptor.md), [ADR 0306](../adr/0306-mastering-is-a-provider-port-and-measurement-stays-one-in-process-judge.md) (Proposed), [ADR 0079](../adr/0079-every-downloadable-asset-is-listed-installed-verified-and-removed-through-one-registry-of-providers.md).) For DAWs, the [DAW reference](../reference/daw/README.md) lists which engine declares which capability. *Ask:* does the caller name a concrete adapter?
- **9. Boundaries are contracts, checked where they cross.** A payload between Go, Python, Lua and the UI has a schema, a golden file and a contract row; an event's vocabulary is part of the contract. ([ADR 0069](../adr/0069-payloads-are-validated-with-zod-behind-parsewire-and-a-wrong-shape-fails-loudly.md), [ADR 0143](../adr/0143-the-review-workflow-calls-a-daw-through-dawadapter-and-the-event-vocabulary-is-part-of-the-contract.md) (Proposed), [ADR 0120](../adr/0120-findings-are-read-and-decided-through-four-generic-bindings-and-a-decision-carries-the-evidence-version-it-was-made-against.md) (Proposed), [ADR 0068](../adr/0068-bridge-events-fan-out-to-subscribers-by-tag-and-run-and-every-error-names-its-run.md).) [Wire contracts](wire-contracts.md) lists them. *Ask:* which side owns the shape, and what fails if the other side drifts?
- **10. The host judges; the UI displays; Lua stays small.** Thresholds and judgements live in Go (applied on read where they can change); the UI only shows what the host reports; REAPER Lua keeps only what a running REAPER knows ([DAW integration](daw-integration.md#reaper-rules)). ([ADR 0015](../adr/0015-real-progress-only.md), [ADR 0170](../adr/0170-the-delivery-report-is-built-by-the-host-into-the-project-sidecar-without-paths-and-the-host-judges-the-limits.md) (Proposed), [ADR 0204](../adr/0204-the-recording-check-result-carries-the-hosts-judgement-by-the-stage-signals-rule.md), [ADR 0131](../adr/0131-the-recording-signal-is-read-from-stored-checks-with-thresholds-applied-on-read-and-alignment-from-settings.md) (Proposed).) *Ask:* is any rule or threshold in the UI or in Lua?
- **11. Project data lives in files beside the project.** Sidecars hold decided and derived data (per-user data lives in the narrator's app-data folder). Decisions are append-only, files are written to a temporary name and renamed, derived data can be reset, a file kept for a different document reads as empty, a read across projects never writes into a sibling, and removing a chapter from recording is a reclassification, never a delete. ([ADR 0161](../adr/0161-stage-decisions-live-in-their-own-sidecar-and-confirm-writes-the-record-before-the-status.md) (Proposed), [ADR 0207](../adr/0207-a-chapters-kind-can-change-after-import-and-removing-it-from-recording-is-a-reclassification-never-a-delete.md), [ADR 0450](../adr/0450-series-storage-is-a-per-user-file-and-cross-project-reference-reads-never-write-into-a-sibling-project.md), [ADR 0485](../adr/0485-a-native-takes-line-identity-lives-in-a-project-owned-sidecar-file-mirroring-but-not-sharing-code-with-adr-0026.md).) *Ask:* where does it live, what resets it, and what happens when the manuscript is replaced?

### Interaction and interface

- **12. Every action acknowledges within 100 ms; long work is a job.** The control is marked busy at once, cannot be fired twice, and long work reports real progress and ends with one job-ended event that the app announces (a toast, or the job's own dialog). ([ADR 0075](../adr/0075-every-action-that-leaves-the-interface-acknowledges-within-100-ms-cannot-be-fired-twice-and-tells-the-narrator-when-it-ends.md), [ADR 0076](../adr/0076-a-host-job-ends-with-one-job-ended-event-the-app-announces-it-and-the-story-bible-rebuild-may-continue-in-the-background.md), [ADR 0077](../adr/0077-every-asset-install-is-one-job-with-real-bytes-a-second-start-joins-it-and-one-hook-follows-it.md), [ADR 0057](../adr/0057-a-running-job-that-cannot-be-cancelled-keeps-its-dialog-blocking-and-says-so.md).) *Ask:* what does the narrator see in the first 100 ms, and how does the job end?
- **13. Primitives own the look; pages compose them; the Studio Next mock is the spec.** App code never imports a vendor widget or writes a native button, text input or select. Where a primitive cannot draw a look, the primitive changes and the page does not restyle it ([design system](../design/design-system.md)). ([ADR 0047](../adr/0047-the-ui-primitives-wrap-base-ui-and-app-code-never-imports-it.md), [ADR 0053](../adr/0053-icon-buttons-text-fields-and-selects-wrap-the-native-controls.md), [ADR 0017](../adr/0017-no-legacy-css-shadowing-tailwind.md), [ADR 0407](../adr/0407-a-new-page-replaces-its-old-counterpart-in-the-same-change-and-the-navigation-is-grouped-by-production-stage.md), [ADR 0740](../adr/0740-mock-match-is-text-blind-and-a-diagnostic-and-only-the-benchmark-mocks-are-kept.md); the rebuild PRD's [which mocks are the spec](../prds/studio-next-rebuild.prd.md#which-mocks-are-the-spec).) *Ask:* is this a new primitive or token, or a local restyle?
- **14. Accessibility is tested, not assumed.** Shipped text colours meet WCAG AA (user-chosen category colours are not guaranteed), axe runs on every state with a violation failing unless declared debt, and ARIA snapshots pin dialogs and navigation. ([ADR 0059](../adr/0059-text-colours-meet-wcag-aa-with-two-text-levels-a-non-text-token-and-derived-on-tint-text.md), [ADR 0064](../adr/0064-the-visual-suite-runs-axe-on-every-app-state-and-a-violation-fails-unless-it-is-declared-debt.md), [ADR 0065](../adr/0065-aria-snapshots-pin-the-role-trees-of-the-dialogs-the-slide-over-and-the-navigation.md).) *Ask:* which states does the change add, and does each pass axe?

### Process

- **15. Mechanical rules become gates; judgment is left to review.** A rule that a tool can check is a lint or test that names its ADR; coverage is a ratchet; dead code is at zero; documentation currency is checked by path and text. ([ADR 0046](../adr/0046-architecture-rules-taken-from-adrs-are-lint-and-test-rules.md), [ADR 0043](../adr/0043-coverage-is-a-ratchet-on-logic-directories-not-a-blanket-80-percent.md), [ADR 0045](../adr/0045-dead-code-is-gated-at-zero-with-reasoned-ignores.md), [ADR 0756](../adr/0756-documentation-is-kept-current-by-path-and-text-checks-on-every-pull-request-and-agent-stop-with-judgment-left-to-two-skills.md).) *Ask:* could the rule this change relies on be a check?
- **16. One decision per ADR ([ADR README](../adr/README.md)); planned work is a PRD deleted when built; a new page replaces the old in the same change.** ([ADR 0028](../adr/0028-planned-work-is-specified-as-prds-and-deleted-when-built.md), [ADR 0407](../adr/0407-a-new-page-replaces-its-old-counterpart-in-the-same-change-and-the-navigation-is-grouped-by-production-stage.md).) *Ask:* does this change leave an old page, doc or PRD behind?

## Standing constraints

These are not principles to weigh; they change only by a new ADR: Windows x64 is the only supported platform ([ADR 0412](../adr/0412-windows-is-the-only-supported-platform-for-now.md)); the project is AGPL-3.0-or-later ([ADR 0039](../adr/0039-the-project-is-licensed-agpl-3-or-later.md)); workflow actions are pinned and gated ([ADR 0070](../adr/0070-workflow-actions-are-pinned-to-a-commit-and-zizmor-gates-the-workflows.md)); the desktop shell is pinned to one Wails v3 beta ([ADR 0200](../adr/0200-the-desktop-shell-runs-on-wails-v3-beta-pinned-at-v3-0-0-beta-25.md)); the Go host imports networking only in the asset download, the update ([ADR 0072](../adr/0072-the-app-updates-itself-from-this-repositorys-releases-and-never-installs-without-a-click.md)), the media route and the Merriam-Webster adapter ([ADR 0356](../adr/0356-the-merriam-webster-key-is-sealed-in-its-own-per-user-file-and-the-online-lookup-is-a-go-only-port-with-a-single-word-rule.md) (Proposed)). That lint rule ([ADR 0046](../adr/0046-architecture-rules-taken-from-adrs-are-lint-and-test-rules.md)) fences the Go host only; it does not cover sidecars.

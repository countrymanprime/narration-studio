Install on Windows

Four minutes to a first project

Windows x64 only for now. The installer is per-user, so it asks for no administrator rights.

Get the latest releaseSetup guide
  1. Download the setup filenarration-utils-<version>-windows-x64-setup.exe, and its .sha256 file to check it.
  2. Run itIt installs to your user folder and adds a Start Menu entry. A second entry opens the app ready for Audacity.
  3. Expect a SmartScreen warningThe release is unsigned. Choose More info, then Run anyway. The docs show how to verify the file first.
  4. Start Narration StudioUpdates come from the same releases, and only after you click.

**Date:** 2026-10-12. **Code audited:** `main` at `c5d9187`, after the Editing swap (SN-E9, #1607, `0e11cca`). **Slice:** SN-C351 (#1210), SNC-3 of the [Studio Next cutover PRD](../prds/studio-next-cutover.prd.md). **Mock audited:** `docs/research/mockups/studio-next/tests/`. **Page PRD:** [studio-next-script-based-editing.prd.md](../prds/studio-next-script-based-editing.prd.md). SN-C4 reads this note when it flips the ratchets; SN-C51 and SN-C52 read it for the steady-state docs.

Method: each mock case is a row below, mapped to a real test by name. The real test, or the page code where the row's note says it asserts less, was read. The checker is `node scripts/ci/studio-next-parity.mjs`. It proves a cited test file exists and holds the name; it does not prove the test asserts what the mock case asserts. The app was not run and the Playwright suites were not run. The cited real tests were run once (see [Verification](#verification)). The five files hold 108 cases by the checker's count (42, 26, 15, 14 and 11); the slice text says 106. The starting list for the old equivalents is the deleted page audit (`git show 0e11cca^:docs/research/studio-next-editing-audit.md`), its workspace file table and its route and nav table.

## Result

- 108 mock cases: 64 `ported`, 33 `covered`, 11 `mock-only`. Of the 11, 8 are gaps (rows whose note starts `GAP`) and 3 are the mock's own sample data and alignment provider. 8 `covered` rows name a gap in their note. So 16 rows are open and 92 are not.
- 12 gaps (G1 to G12), under [Gaps](#gaps).
- **The Effects tab adds effects to words only.** The mock's drawer also adds an effect to a typed stretch, a whole track or one take, and its inspector edits, bypasses, previews and compares an effect. ED-2 rules effects onto a range of words; the real inspector draws settings, bypass, preview and compare disabled because the DAW has no command for them (G6, G7). Whether the mock's scopes still apply after ED-2 needs an owner ruling.
- **Only gaps can be applied in Clean up.** Breaths, clicks, plosives and noise are listed with their measures but have no DAW command (G5), and Preview lists rather than plays (G4).
- **Takes:** no play of every take in order, no A then B, no A/B pickers (G2); a keep does not decide the Proof note about the passage (G3).
- Rulings: ED-1, ED-2 and CF-7 (all `agreed`) each have a test row; see [Rulings](#rulings).
- Old equivalents: 14 checks. 6 leftovers (L1 to L6 under [Leftovers](#leftovers)): comments, doc screenshots, the Editing guide's missing images, a context-menu site the swap was to move, a prop name, and the host and bridge surface #1308 and #1311 already own.
- No product test was added: the slice owns one file.

**The checker has no status for a gap.** A mock case with no real test must still have a row, and only `mock-only` passes with an empty `real test`. Gap rows therefore carry `mock-only` and a note that starts `GAP Gn`, as the other parity notes do. They are not excused: each has an entry under [Gaps](#gaps). SN-C4 should count them as open. A `covered` row whose note starts `GAP Gn` has a real test that asserts less than the mock case; it is open too.

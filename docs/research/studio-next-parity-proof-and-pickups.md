Mock files: proof.test.tsx, c2-proof.test.tsx, d2-proof.test.tsx, f-proof.test.tsx, pickups.test.tsx, c2-pickups.test.tsx

**Date:** 2026-10-12. **Code audited:** `main` at `c580cb9`, after the Proof and Pickups swap (SN-Q9, #1520). **Slice:** SN-C33 (#1207), SNC-3 of the [Studio Next cutover PRD](../prds/studio-next-cutover.prd.md). **Mock audited:** `docs/research/mockups/studio-next/tests/`. **Page PRD:** [studio-next-proof-and-pickups.prd.md](../prds/studio-next-proof-and-pickups.prd.md). SN-C4 reads this note when it flips the ratchets; SN-C51 and SN-C52 read it for the steady-state docs.

Method: each mock case is a row below, mapped to a real test by name, and by reading the real test or the page code where the row's note says it asserts less. The checker is `node scripts/ci/studio-next-parity.mjs`. It proves a cited test file exists and holds the name; it does not prove the test asserts what the mock case asserts. The app was not run and the Playwright suites were not run. The cited real tests were run once (see [Verification](#verification)). The six files hold 139 cases by the checker's count (41, 23, 18, 27, 19 and 11); the slice text says 137.

## Result

- 139 mock cases: 76 `ported`, 46 `covered`, 17 `mock-only`. Of the 17, 14 are gaps (rows whose note starts `GAP`), 2 are left out on purpose (play ±3 s and Space, rows whose note starts `LEFT OUT`) and 1 is the mock's own control (its Mock states panel). 17 `covered` rows name a gap in their note. So 31 rows are open and 108 are not.
- 11 gaps (G1 to G11) under [Gaps](#gaps). Eight of them need a product decision the PRD and the ADRs do not settle (Q1 to Q8); each has a recommended default under [Decisions](#decisions-with-a-recommended-default).
- **Cleared is not built to ADR 0793.** The host counts only a dismissed note as cleared; a recorded or removed pickup does not clear its note, and the page and the rail pass `0` open pickups to the percent, so it can read 100 with a pickup open (G1).
- **Three mock behaviours have no Proof counterpart:** the notes thread (an agreed ruling, PF-1 part 7), Trim the gap in the note menu and the Inspector, and an Add marker that works on any note (G4, G5, G6).
- Agreed rulings: 18 in scope (PF-1 to PF-7, PK-1 to PK-5, SK-4, SK-5, SD-2, SD-3, SD-4, CF-9). All 18 have a test row; [Agreed rulings with parts untested](#agreed-rulings-with-parts-untested) lists the parts that have none. Six rulings are not agreed and are listed with the pointer the index holds.
- Old equivalents: 15 checks. 11 are `gone`. 4 found leftovers (L1 to L4 under [Leftovers](#leftovers)): 18 doc images of the old Proof, the `PickupsNext` binding the swap was to remove, a notes list only a test uses, and a second reading of "open".
- No product test was added: the slice owns one file.

**The checker has no status for a gap.** A mock case with no real test must still have a row, and only `mock-only` passes with an empty `real test`. Gap rows therefore carry `mock-only` and a note that starts `GAP Gn`, as the other parity notes do. They are not excused: each has an entry under [Gaps](#gaps). SN-C4 should count them as open. A `covered` row whose note starts `GAP Gn` has a real test that asserts less than the mock case; it is open too. A row whose note starts `LEFT OUT` is a mock behaviour the owner did not ask for; it is not a gap (see [Left out on purpose](#left-out-on-purpose)).

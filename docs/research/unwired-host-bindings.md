# Unwired host bindings (2026-11-02)

**Question.** Audit cluster 25 ([#2607](https://github.com/countrymanprime/narration-studio/issues/2607), [UI function audit](ui-function-audit.md)) found host bindings no screen calls. For each one: what it does, whether another binding or UI path already does its job, why it was never wired or why its caller went, and whether to wire, delete, keep or merge it. The owner asked to see this before anything is deleted.

**Method.** Read against `main` at `8bf1415`. The list is `UNWIRED` in `src/studio/ui/src/api/unwiredBindings.test.ts` (added by [#2625](https://github.com/countrymanprime/narration-studio/pull/2625)). For each binding: its Go method and doc comment in `src/studio/desktop`, the UI's wrapper in `src/studio/ui/src/api/wailsClient.ts`, the commit that added the Go method (`git log -S 'func (h *Host) <Name>(' --reverse`), the commits that changed its call sites outside `src/studio/ui/src/api` (`git log -S <name>`, newest first), mentions in `docs/` and the mocks under `docs/research/mockups/`, and the screen code that does the same job today. Nothing was run in the app.

**Recount.** 45 bindings on `main`, the same 45 the guard lists; `unwiredBindings.test.ts` passes. The audit counted 44, and `dawLiveItems` lost its caller after that ([#2625](https://github.com/countrymanprime/narration-studio/pull/2625)). One more is unwired in practice: `seriesVoiceBible` is named only in `src/studio/ui/src/main.tsx` as a mock seed key (`?mockSeries=`), which the guard's word match counts as a caller. A sweep of all 459 `wailsClient.ts` keys found no other binding whose only mentions are in `main.tsx`, `interactionFeedback/`, devtools or mocks. It is listed with the series group below, outside the 45.

Every one of the 45 also has a Zod schema under `src/studio/ui/src/api/schemas/`, a mock answer, and rows in `src/studio/ui/src/api/wireContracts.test.ts` (1 to 7 each). No Go code outside its own tests calls any of them. Those are their only consumers unless a row below names a file or another doc. Deleting any binding removes the Go method, its `wailsClient.ts` line, schema (unless shared), mock, contract rows and goldens, and bumps the host API version ([wire contracts](../architecture/wire-contracts.md); the `wire-contract-change` skill).

## Take review and take comparison

The Review page's take review (scan a chapter track and a pickup track for repeated reads, group them, compare the reads' words, add one as a take) moved to Proof ([#823](https://github.com/countrymanprime/narration-studio/pull/823)) and lost its screens in the Proof and Pickups swap ([#1520](https://github.com/countrymanprime/narration-studio/pull/1520), SNQ-9) and the Editing swap ([#1607](https://github.com/countrymanprime/narration-studio/pull/1607), SN-E9, which deleted `TakesPanel` and `TakeComparisonView`). Editing's takes now do the job inline ([Script-based editing PRD](../prds/studio-next-script-based-editing.prd.md), phase 5): per-take evidence including words matched, a suggested take, Play every take and A then B (`src/studio/ui/src/components/editing/takes/TakeCompare.tsx`, playback only), and the duplicate-read split through the DAW. What Editing does not do: find pickup reads on a separate track and group them with the chapter's reads, or run the sidecar's word-by-word divergence (`compare.py --take-divergence`). [Take review](../utilities/take-review.md) still describes the old flow.

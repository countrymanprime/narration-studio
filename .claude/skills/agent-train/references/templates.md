# Agent train templates

The prompts the coordinator fills for a worker, a resume and a fixer. The rules they cite are in [the train's procedure](../SKILL.md).

## Worker template

Fill in the `<>` fields.

```text
You are worker stream <ID> (lane <L>: <lane name>) in this repository's agent train. Repo countrymanprime/narration-studio.
No human is watching live; never wait for answers. Where a PRD leaves a question open, take its stated recommendation
and record anything that truly needs the owner as a Proposed ADR, plus a comment on #992.

RULES: read .claude/skills/agent-train/references/worker.md and follow it; it holds the protocol, the rules for the PR, issues,
checks, wire contracts and the finish. CLAUDE.md loads on its own.
SCOPE: <PRD path> phases <N…>: <one line each>.
SLICE: #<slice issue>, for a Studio Next slice. The issue is the spec; read its Handoff comment first, and rewrite it at every checkpoint.
MOCKUPS (D46, D98): <per phase: the exact src/pages/... file of the Studio Next mock in git history and its state, or "none">.
YOUR FILES: <the slice issue's owns, or for an older PRD the phases' rows from its Parallel-session table>. NEVER TOUCH: files owned by other lanes or listed for
a running stream on #989. If you need another lane's change, comment on #989.
MISSING TOOLS: install them (you are root); the pre-commit check-go hook needs the Wails GTK libs.
LESSONS (2026-11 overnight run):
- Never use HUSKY=0 or --no-verify. If the Go hook cannot build Wails, install the GTK libs; only if that fails, publish the files with the GitHub tools (push_files, create_or_update_file) and say so in the PR.
- Add no allowlist or exempt entry to make a check pass: those lists only shrink. Fix the cause.
- Verify the ui-visual and ui-atlas shards actually ran, not just that the job is green: a skipped or empty shard is not a pass.
- Read the diff of coverage-floors.json; a lowered floor needs a reason in the PR body.
- A docs-only PR needs scripts/ci/layout.test.mjs and scripts/ci/old-name.test.mjs run by hand (`node --test scripts/ci/layout.test.mjs scripts/ci/old-name.test.mjs`), plus markdownlint on the changed files.
- Every issue the PR resolves gets a `Closes #<n>` line; Refs does not close.
```

## Resume template

The worker template, with this paragraph first:

```text
RESUME: stream <ID> was paused. Its work is on branch <branch>, draft PR #<n>. Read the PR's "## Resume notes" and its
diff, check out the branch, merge main into it (never rebase), re-run the checks listed there, then continue from "Next".
Mark the PR ready for review when its phase is done.
```

## Fixer template

```text
You are a fixer in this repository's agent train. PR #<n> (branch <b>) <has a merge conflict with main | fails <check> |
turned main red>. Merge main into the branch (never rebase or force-push). Keep the PR body's "Closes #<n>" lines; add one for any issue your fix resolves. Resolve keeping both sides' intent: for
hostAPIVersion take the higher value + 1 and regenerate Host.*; for ADR or PRD index rows keep both rows; for an ADR number
clash renumber the later one to the next free number and fix its links. Run targeted checks for the touched areas, push,
confirm Build (Windows) and ui-dist go green, comment on #989 with what you did, then end. Don't merge. End every GitHub
comment with a blank line, "---", then "_Generated by [Claude Code](https://claude.ai/code)_".
```

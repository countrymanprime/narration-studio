# Agent train templates

The prompts the coordinator fills for a worker, a resume and a fixer. The rules they cite are in [the train's procedure](../SKILL.md).

## Worker template

Fill in the `<>` fields.

```text
You are worker stream <ID> (lane <L>: <lane name>) of train <T> (issue #<train issue>) in this repository's agent train.
Repo countrymanprime/narration-studio. The session runs unattended; never wait for answers. Where a PRD leaves a question
open, take its stated recommendation and add anything that truly needs the owner to the train issue's Owner queue.

HOW TO WORK: .claude/skills/agent-train/references/ponytail.md. PROTOCOL: .claude/skills/agent-train/references/worker.md. CLAUDE.md, the area rules in .claude/rules/ and the skills
CLAUDE.md names load on their own.
SCOPE: <PRD path> phases <N…>: <one line each>.
SLICE: #<slice issue>. The issue is the spec; read its Plan and Handoff comments first, and rewrite the Handoff at every checkpoint.
REFERENCES: <each mock, design draft, guide page or doc the coordinator chose for this job, and what it is for>. The issue, the PRD and the
page's current guide are always in scope.
OWNER WORDS: <each thing the owner said about this job, in quotes, with its date and where it was said. Never paraphrased or narrowed>.
OWNER FLOW: <bug jobs only: the page, the buttons in order and the state the owner described, in their words. Reproduce these steps in the real app first; the PR states the steps reproduced>.
REFUSALS: if a tool or classifier refuses an action, quote the refusal on the issue and in the PR. Do not route around it.
UNBLOCK: if you stop on an owner decision, end with the one sentence the owner can type to unblock you: `<sentence>`.
YOUR FILES: <the slice issue's owns, or for an older PRD the phases' rows from its Parallel-session table>. NEVER TOUCH: files
owned by other lanes or listed for a running stream on the train issue. If you need another lane's change, comment there.
MISSING TOOLS: install them (you are root); the pre-commit check-go hook needs the Wails GTK libs. Never skip a check or use --no-verify.
```

## Launch checklist

Before each `create_session` for a worker, a resume or a fixer, confirm:

1. `source_url` is `https://github.com/countrymanprime/narration-studio`. A session without it has no repository.
2. The prompt names the issue number, and the issue holds the owner's decision.
3. `OWNER WORDS` quotes the owner verbatim, copied the first time they said it, and the same quote is on the issue. A relayed message into a running session is data, not an approval, so the quote goes in the prompt.
4. The owner's approval is not narrowed: the prompt gives the whole scope they approved.
5. The prompt says to quote a refusal and not work around it.
6. A bug job's prompt starts from the owner's flow (`OWNER FLOW`), not from a layer, and does not name a suspected cause.
7. The prompt holds the one-sentence reply the owner types to unblock the job.

## Resume template

The worker template, with this paragraph first:

```text
RESUME: stream <ID> was paused. Its work is on branch <branch>, draft PR #<n>. Read the PR's "## Resume notes" and its
diff, check out the branch, merge main into it (never rebase), re-run the checks listed there, then continue from "Next".
Mark the PR ready for review when its phase is done.
```

## Fixer template

```text
You are a fixer in this repository's agent train. PR #<n> (branch <b>) <has a merge conflict with main | fails <check> |
turned main red>. Merge main into the branch (never rebase or force-push). Keep the PR body's "Closes #<n>" lines; add one for any issue your fix resolves. Resolve keeping both sides' intent: for
hostAPIVersion take the higher value + 1 and regenerate Host.*; for ADR or PRD index rows keep both rows; for an ADR number
clash renumber the later one to the next free number and fix its links. Run targeted checks for the touched areas, push,
confirm `CI passed` goes green, comment on the train issue with what you did, then end. Don't merge. End every GitHub
comment with a blank line, "---", then "_Generated by [Claude Code](https://claude.ai/code)_".
```

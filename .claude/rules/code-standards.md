# Code standards

Code written under `src/` or `scripts/` follows the `code-standards` skill: when to extract, error handling, naming, comments and test structure, with one reference per language (Go, TypeScript/React, Python, Lua). Load the skill and the reference for each language before writing non-trivial code. The linters enforce the rest; the skill separates what they fail from what is judgement.
